# 홈 화면 작업 요약 섹션 기능 명세서

**상태**: ✅ 구현 완료 (2025-09-21)
**구현된 파일**: app/components/Home.tsx
**주요 변경사항**: 동기부여 명언 섹션 추가, 중앙 정렬 디자인 적용

## 개요

- 홈 화면에 어제 수행한 일들을 요약해서 보여주는 섹션 추가
- 사용자가 진행한 부분에 대해 보람을 느낄 수 있도록 하는 긍정적인 피드백 제공
- 현재는 실제 데이터가 없으므로 명언을 활용한 가짜 데이터로 구현

## 요구사항

### 기능적 요구사항

- 어제의 작업 내용을 요약하여 표시
- 진행 상황에 대한 긍정적인 피드백 제공
- 현재 단계에서는 명언을 활용한 가짜 데이터 표시
- 중앙 정렬된 세련된 디자인

### 비기능적 요구사항

- 모바일 우선 반응형 디자인
- 라이트/다크 모드 지원
- 로딩 상태 고려 (향후 실제 데이터 연동시)
- 접근성 준수 (스크린 리더 지원)

## 디자인 고려사항

- `docs/design-guide.md`의 색상 시스템 적용
- 카드 형태의 컨테이너 사용 (`card-default` 클래스)
- 중앙 정렬로 시각적 균형감 확보
- Microsoft Fluent 2 디자인 원칙 적용
- 8px 기반 간격 시스템 사용

## 구현 계획

### 1단계: 컴포넌트 구조 설계
- 기존 Home 컴포넌트에 작업 요약 섹션 추가
- 카드 형태의 컨테이너로 구성
- 명언 데이터 배열 생성

### 2단계: UI 구현
- 중앙 정렬된 텍스트 레이아웃
- 명언과 작가명을 구분하여 표시
- 적절한 타이포그래피 적용

### 3단계: 가짜 데이터 생성
- 동기부여가 되는 명언들 선정
- 한국어 명언으로 구성
- 일상적인 성취감을 느낄 수 있는 내용

## 테스트 계획

- 텍스트 렌더링 확인
- 반응형 레이아웃 테스트
- 다크모드에서의 가독성 확인
- 접근성 속성 검증

## 구현 결과

### 추가된 기능
- 5개의 동기부여 명언 배열 생성
- 페이지 로드시 랜덤 명언 선택 로직
- 카드 형태의 중앙 정렬 디자인
- 명언과 작가명을 구분한 타이포그래피

### 적용된 디자인 요소
- `card-default` 클래스 사용
- `heading-secondary`, `body-text`, `caption-text` 타이포그래피 적용
- `blockquote`와 `cite` 요소로 시맨틱 마크업
- 중앙 정렬 및 적절한 여백 설정

### 향후 개선 방향
- 실제 작업 데이터 연동시 API 연결
- 사용자별 맞춤형 메시지 표시
- 진행률 표시 컴포넌트 추가

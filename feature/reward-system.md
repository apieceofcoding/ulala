# 보상 시스템 기능 명세서

**상태**: ✅ 구현 완료 (2025-01-24)
**구현된 파일**:
- app/routes/rewards.tsx (새로 생성)
- app/routes/stories.tsx (수정)
**주요 변경사항**: 할 일 완료 시 자동 보상 생성 및 보상 탭 구현

## 개요

사용자가 스토리 탭에서 할 일을 완료했을 때 자동으로 보상을 생성하고, 보상 탭에서 획득한 보상을 확인할 수 있는 게이미피케이션 시스템입니다.

### 목적과 필요성
- 사용자의 할 일 완료에 대한 동기부여 증진
- 성취감과 지속적인 참여 유도
- 카테고리별 차등 보상으로 다양한 활동 장려

## 요구사항

### 기능적 요구사항
1. **할 일 완료 시 자동 보상 생성**
   - 스토리 탭에서 할 일 체크박스 클릭 시 보상 자동 생성
   - 카테고리별 차등 포인트 지급
   - 보상 정보 로컬 스토리지 저장

2. **보상 탭 구현**
   - 누적 포인트 표시
   - 최근 획득한 보상 목록 (시간순 정렬)
   - 보상 유형별 시각적 구분
   - 새 보상 알림 기능

3. **보상 유형 시스템**
   - 포인트: 할 일 완료 시 지급되는 기본 보상
   - 뱃지: 특별한 달성 시 지급
   - 업적: 연속 완료 등 특별 조건 달성 시

### 비기능적 요구사항
- 로컬 스토리지를 통한 데이터 영속성
- 3초 후 새 보상 알림 자동 제거
- 모바일 우선 반응형 디자인
- 라이트/다크 모드 지원

## 디자인 고려사항

### docs/design-guide.md 적용 원칙
- **일관성**: 기존 카드 컴포넌트 (`card-default`, `card-clickable`) 재사용
- **가독성**: 타이포그래피 클래스 (`heading-primary`, `body-text`, `caption-text`) 활용
- **단순성**: 직관적인 아이콘과 색상으로 보상 유형 구분
- **자연스러운 구분**: 테두리 없는 디자인으로 배경색 차이 활용

### 사용할 컴포넌트와 색상 시스템
- 색상: `text-primary` (포인트), `text-accent` (뱃지), `text-secondary` (업적)
- 카드: `card-default`, `card-clickable` 스타일 적용
- 간격: 8px 기반 간격 시스템 (`space-y-6`, `gap-3` 등)
- 아이콘: 이모지를 활용한 직관적 시각화

## 구현 계획

### 1단계: 보상 데이터 구조 설계 ✅
```typescript
interface Reward {
  id: number;
  title: string;
  description: string;
  earnedAt: string;
  type: 'points' | 'badge' | 'achievement';
  value?: number;
  icon: string;
  isNew?: boolean;
}
```

### 2단계: 보상 탭 페이지 구현 ✅
- 누적 포인트 표시 영역
- 보상 목록 렌더링
- 새 보상 알림 UI
- 보상 안내 정보 섹션

### 3단계: 스토리 탭 연동 ✅
- `handleToggleTodo` 함수에 보상 생성 로직 추가
- 카테고리별 차등 보상 설정
- 로컬 스토리지 연동

### 4단계: 사용자 경험 최적화 ✅
- 새 보상 시각적 강조 (ring-2 ring-primary)
- 시간 표시 포맷팅 (오늘/어제/N일 전)
- 보상 유형별 색상 구분

# 내정보 페이지 기능 명세서

**상태**: ✅ 구현 완료 (2025-01-24)
**구현된 파일**: app/routes/profile.tsx
**주요 변경사항**: 사용자 프로필, 통계, 설정 기능 구현

## 개요

사용자의 프로필 정보, 활동 통계, 앱 설정을 한 곳에서 관리할 수 있는 페이지입니다.

### 목적과 필요성

- 사용자의 전체 활동 현황 한눈에 파악
- 개인화된 통계 및 성과 확인
- 앱 설정 및 테마 관리
- 사용자 경험 개인화

## 요구사항

### 기능적 요구사항

1. **프로필 정보 표시**
   - 사용자 레벨 및 경험치
   - 이름 및 가입 정보
   - 프로필 이미지 (아바타)

2. **활동 통계**
   - 총 완료한 할 일 수
   - 누적 포인트
   - 연속 달성 일수
   - 주간/월간 완료율

3. **설정 기능**
   - 다크 모드 토글
   - 알림 설정
   - 언어 설정
   - 데이터 초기화

4. **추가 기능**
   - 업적 목록
   - 최근 활동 내역
   - 앱 정보 및 버전

### 비기능적 요구사항

- 로컬 스토리지 기반 설정 저장
- 즉각적인 테마 변경 반영
- 모바일 우선 반응형 디자인
- 라이트/다크 모드 지원

## 디자인 고려사항

### docs/design-guide.md 적용 원칙

- **일관성**: 기존 디자인 컴포넌트 재사용
- **가독성**: 명확한 정보 계층 구조
- **단순성**: 직관적인 설정 인터페이스
- **자연스러운 구분**: 테두리 없는 카드 디자인

### 사용할 컴포넌트와 색상 시스템

- 카드: `card-default` 스타일
- 타이포그래피: `heading-primary`, `heading-secondary`, `body-text`
- 버튼: `btn-primary`, `btn-secondary`
- 색상: `text-primary`, `text-secondary`, `text-tertiary`
- 간격: 8px 기반 시스템

## 구현 계획

### 1단계: 프로필 섹션 구현

- 레벨 및 경험치 바
- 사용자 정보 표시
- 아바타 이미지

### 2단계: 통계 섹션 구현

- 그리드 레이아웃 통계 카드
- 숫자 및 진행률 시각화
- 아이콘과 색상으로 구분

### 3단계: 설정 섹션 구현

- 토글 스위치 컴포넌트
- 설정 항목 리스트
- 로컬 스토리지 연동

### 4단계: 부가 기능 추가

- 업적 및 뱃지 표시
- 앱 정보
- 로그아웃/데이터 초기화

## 페이지 구성

### 1. 프로필 헤더

```
┌─────────────────────────┐
│   [아바타]              │
│   레벨 15               │
│   닉네이메이커          │
│   ▓▓▓▓▓░░░░░ 50%       │
└─────────────────────────┘
```

### 2. 활동 통계

```
┌───────────┬───────────┐
│ 완료 할일  │ 누적점수  │
│   145     │  2,580   │
└───────────┴───────────┘
┌───────────┬───────────┐
│ 연속달성   │ 완료율    │
│  7일      │   85%    │
└───────────┴───────────┘
```

### 3. 설정 메뉴

```
┌─────────────────────────┐
│ 다크 모드        [토글]  │
│ 알림 설정        [토글]  │
│ 언어             한국어  │
│ 데이터 초기화    [버튼]  │
└─────────────────────────┘
```

   - [ ] 반응형 레이아웃 확인

2. **통계 표시 테스트**
   - [ ] 로컬 스토리지 데이터 기반 통계 계산
   - [ ] 실시간 업데이트 반영
   - [ ] 숫자 포맷팅 확인

3. **설정 기능 테스트**
   - [ ] 다크 모드 토글 동작
   - [ ] 설정 저장 및 불러오기
   - [ ] 데이터 초기화 기능

4. **접근성 테스트**
   - [ ] 키보드 네비게이션
   - [ ] 스크린 리더 지원
   - [ ] 색상 대비 확인

- 사용자 시나리오 기반 검증

## 구현 상세

### 레벨 시스템

- 경험치 계산: 완료한 할 일 수 기반
- 레벨업 조건: 10개당 1레벨
- 최대 레벨: 100

### 통계 데이터 소스

- 완료한 할 일: 로컬 스토리지에서 계산
- 누적 포인트: 보상 데이터에서 합산
- 연속 달성: 캘린더 데이터 분석
- 완료율: 전체 대비 완료 비율

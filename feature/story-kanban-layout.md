# 스토리 페이지 칸반(Kanban) 레이아웃 기능 명세서

**상태**: ✅ 구현 완료 (2025-11-02)
**구현된 파일**: `app/routes/stories.tsx`
**추가 라이브러리**: `@dnd-kit/core`, `@dnd-kit/sortable`, `@dnd-kit/utilities`

**주요 변경사항**:
- 태스크를 TODO/IN_PROGRESS/DONE 세 가지 상태로 구분하여 표시
- 각 섹션에 제목과 태스크 개수 표시
- 순환 방식의 상태 변경 (TODO → IN_PROGRESS → DONE → TODO)
- 빈 섹션에 안내 메시지 표시
- 진행중 태스크에 시각적 구분 (파란색 좌측 바, 원형 아이콘)
- **드래그 앤 드롭 기능 추가** (태스크를 섹션 간 이동 가능)
- 드래그 중 시각적 피드백 (투명도, 회전, 오버레이)
- 드롭 영역 강조 (연한 파란색, 점선 테두리)
- 모바일 터치 드래그 지원

## 개요

### 목적
- 스토리 페이지의 태스크를 **할일 / 진행중 / 완료** 세 가지 섹션으로 구분하여 표시
- 태스크 상태(TODO / IN_PROGRESS / DONE)에 따라 시각적으로 명확하게 구분
- 사용자가 자신의 태스크 진행 상황을 한눈에 파악할 수 있도록 개선

### 배경
- 현재 스토리 페이지는 모든 태스크를 하나의 리스트로 표시
- TaskStatus 타입에 이미 TODO, IN_PROGRESS, DONE 세 가지 상태가 정의되어 있음
- 하지만 UI는 완료 여부만 체크박스로 구분하고, TODO와 IN_PROGRESS를 구분하지 않음
- 사용자가 진행 상황을 더 명확하게 파악할 수 있도록 칸반 스타일 레이아웃으로 개선 필요

## 요구사항

### 기능적 요구사항

1. **세 가지 섹션 구분**
   - 화면을 위에서 아래로 **할일 → 진행중 → 완료** 세 개의 섹션으로 나눔
   - 각 섹션은 명확한 제목과 구분선으로 분리
   - 각 섹션에는 해당 상태의 태스크만 표시

2. **섹션별 태스크 필터링**
   - **할일 섹션**: `status === TaskStatus.TODO`인 태스크
   - **진행중 섹션**: `status === TaskStatus.IN_PROGRESS`인 태스크
   - **완료 섹션**: `status === TaskStatus.DONE`인 태스크

3. **태스크 상태 변경**
   - 각 태스크에 상태 변경 버튼 제공
   - TODO → IN_PROGRESS, IN_PROGRESS → DONE, DONE → TODO 순환 가능
   - 또는 드롭다운으로 직접 상태 선택 가능

4. **빈 섹션 처리**
   - 해당 상태의 태스크가 없을 경우 안내 메시지 표시
   - 예: "진행 중인 태스크가 없습니다"

5. **태스크 카운트 표시**
   - 각 섹션 제목 옆에 태스크 개수 표시
   - 예: "할일 (3)", "진행중 (1)", "완료 (5)"

### 비기능적 요구사항

1. **기존 기능 유지**
   - 태스크 생성, 수정, 삭제 기능 유지
   - AI 추천 기능 유지
   - 보상 시스템 유지

2. **반응형 디자인**
   - 모바일에서도 세 섹션이 명확하게 구분되어야 함
   - 작은 화면에서는 각 섹션이 세로로 스크롤 가능

3. **성능**
   - 태스크 수가 많아도 렌더링 성능 유지
   - 불필요한 리렌더링 방지

## 디자인 고려사항

### 적용할 디자인 원칙 (`docs/design-guide.md`)

1. **일관성 (Consistency)**
   - 기존 카드 스타일 유지
   - 색상 시스템 및 간격 시스템 준수

2. **가독성 (Readability)**
   - 각 섹션 제목을 명확하게 구분
   - 충분한 섹션 간 여백 (최소 24px)

3. **단순성 (Simplicity)**
   - 복잡하지 않은 레이아웃
   - 명확한 시각적 계층

4. **자연스러운 구분 (Natural Separation)**
   - 섹션 구분에 두꺼운 테두리 사용 금지
   - 배경색 차이로 자연스럽게 구분
   - 또는 미묘한 구분선 사용 (1px, 연한 색상)

### 사용할 컴포넌트 및 색상

1. **섹션 헤더**
   - `heading-secondary` 클래스 사용
   - 색상: `text-text-primary dark:text-text-primary-dark`
   - 태스크 카운트: `caption-text` 클래스로 표시

2. **섹션 컨테이너**
   - 배경색: `bg-bg-secondary dark:bg-bg-secondary-dark`
   - 패딩: `p-4` (16px)
   - 라운드: `rounded-lg`
   - 섹션 간 간격: `gap-6` (24px)

3. **태스크 카드**
   - 기존 `.card-default` 스타일 유지
   - 진행중 상태는 좌측에 파란색 바 추가 (선택 사항)

4. **빈 상태 메시지**
   - `body-text-small` 클래스
   - 색상: `text-text-tertiary dark:text-text-tertiary-dark`
   - 가운데 정렬

### 접근성

1. **시맨틱 HTML**
   - 각 섹션을 `<section>` 태그로 감싸기
   - 섹션 제목은 `<h2>` 태그 사용

2. **키보드 접근성**
   - 기존 Tab 순서 유지
   - 섹션 간 이동이 논리적으로 흐름

3. **스크린 리더 지원**
   - 각 섹션에 `aria-label` 추가
   - 태스크 카운트도 스크린 리더가 읽을 수 있도록 처리

## 구현 계획

### 1단계: 태스크 필터링 로직 추가
- 태스크 배열을 TaskStatus별로 세 그룹으로 분류
- TODO, IN_PROGRESS, DONE 각각의 배열 생성

### 2단계: 섹션 컴포넌트 구조 설계
- 재사용 가능한 TaskSection 컴포넌트 생성 (선택 사항)
- props: 제목, 태스크 목록, 빈 상태 메시지, 이벤트 핸들러
- 섹션 헤더에 제목과 태스크 개수 표시
- 빈 상태일 경우 안내 메시지 표시

### 3단계: 메인 레이아웃 수정
- 기존 단일 리스트를 세 개의 섹션으로 분리
- 할일 → 진행중 → 완료 순서로 위에서 아래로 배치
- 각 섹션에 필터링된 태스크만 전달

### 4단계: 태스크 상태 변경 UI 개선
- 세 가지 상태를 구분할 수 있는 UI 추가

**옵션 1: 버튼 그룹**
- 각 태스크에 "할일", "진행중", "완료" 버튼 표시
- 현재 상태는 하이라이트 표시
- 다른 상태 클릭 시 변경

**옵션 2: 드롭다운**
- 현재 상태를 드롭다운으로 표시
- 선택 시 상태 변경

**옵션 3: 순환 버튼 (권장)**
- 클릭 시 TODO → IN_PROGRESS → DONE → TODO 순환
- 간단하고 직관적

### 5단계: 상태 변경 로직 추가
- 태스크 상태를 변경하는 핸들러 함수 구현
- useTasks 훅의 editTask 활용
- 상태 변경 시 모달의 selectedTask도 함께 업데이트

## 잠재적 이슈 및 고려사항

1. **기존 UI와의 차이**
   - 사용자가 익숙해질 시간 필요
   - 완료된 태스크가 하단에 있어 찾기 어려울 수 있음 (접기/펼치기 기능 고려)

2. **태스크 수가 많을 경우**
   - 각 섹션이 너무 길어질 수 있음
   - 섹션별 최대 높이 제한 및 스크롤 고려

3. **상태 변경 UI**
   - 세 가지 상태를 명확하게 구분할 수 있는 직관적인 UI 필요
   - 실수로 상태를 변경하는 것 방지

4. **진행중(IN_PROGRESS) 상태 활용**
   - 현재 코드에서는 거의 사용되지 않음
   - 사용자가 이 상태를 언제 사용해야 하는지 안내 필요

## 드래그 앤 드롭 기능 추가 (✅ 구현 완료)

### 개요
태스크를 마우스나 터치로 드래그하여 다른 섹션으로 이동할 수 있는 기능을 추가했습니다.

### 주요 기능
1. **드래그 앤 드롭 인터랙션**
   - 태스크 카드를 드래그하여 할일/진행중/완료 섹션으로 이동
   - 드래그 시작 시 시각적 피드백 (투명도 50%, 회전 효과)
   - 드롭 가능 영역 강조 (연한 파란색 배경, 점선 테두리)
   - 빈 섹션에도 드롭 가능

2. **상태 변경**
   - 할일 섹션에 드롭: TODO로 변경
   - 진행중 섹션에 드롭: IN_PROGRESS로 변경
   - 완료 섹션에 드롭: DONE으로 변경
   - 완료 섹션 드롭 시 보상 생성

3. **모바일 지원**
   - PointerSensor로 터치 드래그 지원
   - 8px 이동 후 드래그 시작 (실수 방지)

4. **기존 기능 유지**
   - 체크박스 클릭 방식도 계속 사용 가능

- **@dnd-kit/core** 라이브러리 사용
- 가볍고 현대적, 터치 지원 우수, 접근성 훌륭

   - useDraggable 훅 사용
   - 드래그 중 opacity 0.5, cursor grabbing
   - transform으로 부드러운 이동

2. **DroppableSection 컴포넌트**

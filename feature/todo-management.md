# 할 일 관리 기능 명세서

**상태**: ✅ 구현 완료 (2025-09-21)
**구현된 파일**: app/routes/records.tsx
**주요 변경사항**: Records 페이지에 완전한 할 일 관리 시스템 구현

## 개요

사용자가 기록 탭에서 할 일을 생성, 관리, 완료할 수 있는 기능을 제공합니다. AI 추천 할 일과 직접 생성 기능을 모두 지원하여 개인화된 목표 설정을 돕습니다.

## 요구사항

### 기능적 요구사항

1. **할 일 추천 기능**
   - "할 일을 만들어볼까요?" 버튼 클릭 시 샘플 할 일 목록 표시
   - 카테고리별 다양한 할 일 제공 (건강, 운동, 학습, 자기계발, 디지털 디톡스)
   - 클릭 한 번으로 할 일 선택 및 추가

2. **직접 생성 기능**
   - "직접 만들래요" 버튼으로 커스텀 할 일 생성 폼 표시
   - 할 일 제목 입력 필드
   - 카테고리 선택 드롭다운 (건강, 운동, 학습, 자기계발, 취미, 기타)
   - 유효성 검증 (빈 제목 방지)

3. **할 일 목록 관리**
   - 생성된 할 일 목록 표시
   - 체크박스를 통한 완료/미완료 토글
   - 삭제 버튼으로 할 일 제거
   - 진행률 표시 (완료: X / Y)

4. **상태 관리**
   - React useState로 로컬 상태 관리
   - TypeScript 인터페이스로 타입 안전성

### 비기능적 요구사항

- 모바일 우선 반응형 디자인
- 라이트/다크 모드 지원
- 접근성 준수 (키보드 네비게이션, ARIA 라벨)
- 부드러운 전환 애니메이션

## 디자인 고려사항

### 적용된 디자인 원칙 (docs/design-guide.md 기반)

- **Microsoft Fluent 2 디자인 시스템**: 일관된 시각적 언어
- **Tailwind CSS v4 커스텀 테마**: 기존 색상 시스템 활용
- **카드 기반 레이아웃**: `card-default`, `card-clickable` 클래스 사용
- **버튼 시스템**: `btn-primary`, `btn-secondary` 클래스 적용
- **색상 시스템**: `text-primary`, `bg-primary` 등 시맨틱 색상 사용
- **8px 기반 간격**: `space-y-3`, `space-y-4`, `space-y-6` 사용

### 사용된 컴포넌트와 색상

- **카드**: `card-default` (기본 카드), `card-clickable` (클릭 가능한 카드)
- **버튼**: `btn-primary` (주요 액션), `btn-secondary` (보조 액션)
- **텍스트**: `heading-secondary`, `body-text`, `caption-text` 타이포그래피
- **색상**: 시맨틱 색상 시스템 (primary, secondary, tertiary)
